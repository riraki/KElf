# ELF test files

[简体中文](README.zh-CN.md)

This directory contains ELF binaries used by KElf's automated tests and examples. These files are test inputs, not runtime dependencies of the library, and are not packaged in the KElf main JAR.

## Files

- `generated/libnative-lib-armeabi-v7a.so` — 32-bit ARM shared object built with the Android NDK fixture project.
- `generated/libnative-lib-arm64-v8a.so` — 64-bit AArch64 shared object built with the Android NDK fixture project.
- `android/arm/libart.so` — 32-bit ARM Android runtime library sample, identified in the project as Android 13 / API level 33.
- `android/arm64/libart64.so` — 64-bit AArch64 Android runtime library sample, identified in the project as Android 13 / API level 33.

The two generated samples can be recreated with `test-fixtures/native-android/build.sh`. The Android runtime library samples are checked-in inputs and are not generated by that script.
